# Dados brutos

Armazene aqui os CSVs originais exportados das sessões de coleta. Os arquivos de dados são ignorados pelo Git por padrão para evitar publicar dados pessoais ou grandes volumes acidentalmente.

Siga o contrato em [../../docs/data-schema.md](../../docs/data-schema.md). Use IDs pseudônimos para participantes. Não altere os arquivos brutos; faça transformações em `data/processed/`.
